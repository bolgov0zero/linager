Linager для iOS: режим «Консоль»

Кликабельный макет. Внизу переключатель режимов «Консоль» и «Дашборд»: только значки, узкая плавающая капсула по центру (своя панель со стеклом iOS 26). В «Консоли» только дерево папок и серверов: точка состояния, имя, бейдж системы. Над списком переключатель типа подключения (Терминал, RDP, Помощник): нажатие на сервер открывает его выбранным способом. Режим, тип подключения и свёрнутые папки запоминаются: нажмите «Перезапустить приложение» справа. Долгое нажатие на сервер (или правый клик): открыть другим способом. Данные вымышлены, ничего никуда не отправляется. Все экраны дашборда.

Что запоминается

Всё хранится на телефоне (UserDefaults, @AppStorage / @SceneStorage), на сервер ничего не уходит.





Правила
    

  • Режим «Консоль»: список без метрик, только папки (любой вложенности), точка состояния и бейдж системы.
    • 

  • Меню «…» сверху: фильтр по системе (Все, Windows, Linux) и по статусу (Все, В сети, Не в сети), с галочкой у выбранного. Фильтры складываются с типом подключения; папки без подходящих серверов скрываются. Пока фильтр включён, на кнопке «…» синяя точка. Фильтры тоже запоминаются.
    • 

  • Нажатие на папку сворачивает и разворачивает её, число справа это серверы внутри (с вложенными).
    • 

  • Поиск плоский: показывает путь папок под именем; по имени, папке и системе.
    • 

  • Нет связи: серый сервер, нажатие объясняет, что подключиться нельзя.
    • 

  • Переключатель типа подключения фильтрует список: серверы без такого подключения (RDP и Помощник на Linux) не показываются, папки без подходящих серверов тоже (на любой глубине). Число у папки считает только видимые серверы. Серверы без связи остаются в списке серыми.
    • 

  • Правила как в приложении для компьютера: Терминал у любого сервера в сети; Помощник у Windows и у Linux с графической консолью (dev-desktop в макете); RDP у Windows, если удалённый рабочий стол не выключен (у file-srv он выключен).
    • 

  • Бейдж системы: только значок (Windows синий, Linux зелёный, как в приложении для компьютера), без подписи; VoiceOver читает «Windows» или «Linux».
    • 

  • RDP пока не готов: вкладка серая, нажатие объясняет «RDP появится позже» и не переключает. Кнопка «RDP: готов» вверху показывает, как будет выглядеть список потом.
    • 

  • Терминал, RDP и Помощник открываются теми же экранами, что уже есть (RDP позже).
    •

Решено
  • Внизу нативная панель вкладок (TabView) со значком и подписью; свой переключатель отвергнут.
  • Адрес в строке не показывается.
  • Учётная запись и ключи: кнопка справа вверху, как сейчас; ключи используются только при подключении в Помощнике.
