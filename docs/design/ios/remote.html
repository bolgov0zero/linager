Linager для iOS: удалённый экран

Кликабельный макет общего экрана Помощника и удалённого рабочего стола (RDP). Путь: нажмите на строку сервера → выберите «Помощник» или «Удалённый рабочий стол» → картинка открывается в альбомной ориентации → панель сверху сворачивается в кнопку, которую можно перетаскивать → «закрыть» возвращает портрет. Данные условные, сервер не нужен.

Что здесь происходит

  1. Строка сервера → меню долгого нажатия (здесь нажатие мышью). Пункты зависят от сервера: Windows даёт оба режима, Linux с графической консолью только «Помощник», сервер без экрана ни одного.
  2. RDP сначала спрашивает логин и пароль (форму можно заполнить из «Ключей»); Помощник подключается сразу.
  3. При подключении телефон поворачивается в альбомную ориентацию, картинка на весь экран, вписана по высоте.
  4. Панель сверху сворачивается стрелкой справа в круглую кнопку. Кнопку можно перетащить, она прилипает к левому или правому краю. Нажатие возвращает панель.
  5. Кнопка клавиатуры открывает системную клавиатуру со стеклянной строкой клавиш; панель при этом сама сворачивается в кнопку, а картинка не уменьшается и следует за указателем (вернётся, когда клавиатура закроется).
  6. «Закрыть» (крестик слева) завершает подключение и возвращает портрет.
