# Обратный прокси

Веб-панели Linager больше нет (удалена в 0.10.0-beta.17), поэтому обратный прокси (Caddy, nginx, Nginx Proxy Manager) для сервера не нужен и не поддерживается. Интерфейс сервера это приложение Linager, оно подключается к порту приложения напрямую по TLS с закреплением сертификата: [подключение](connection.md), [приложение](app.md). Ограничить, кто может подключаться, можно в «Настройки → Доступ к серверу»: [access.md](access.md).

Если у вас остался Caddy или nginx, который установила прежняя версия установщика для админки, его можно удалить: Linager на него больше не опирается.
