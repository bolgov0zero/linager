# Linager

Открытая система управления серверами на Debian: сервер с админкой и агенты на управляемых серверах. Подробности: `docs/kickoff/PROMPT.md` (или `PROMPT.md` из стартового пакета), `docs/decisions.md`, `docs/design/ui-spec.md`.

## Правила
- Язык кода, идентификаторов, комментариев, коммитов: английский. Документация и интерфейс: русский основной, английский второй (всё через i18n).
- Go, один бинарник `linager` с ролями server и agent. Приложение для рабочего стола (`app/`, Wails v3) отдельный бинарник и отдельный Go-модуль: серверу и агенту не нужен web view. Платформы: Debian 12 и 13, Ubuntu 22.04, 24.04 и 26.04 LTS (семейство apt/systemd), amd64; arm64 только для агента (Raspberry Pi 4 с 64-разрядной ОС). Windows x64 (10/11, Server 2016+): только агент (docs/ru/windows.md).
- PostgreSQL только локальный. Миграции только вперёд.
- Эталон интерфейса приложения: `docs/design/redesign/index.html` (вариант A, компактный, без фиолетового, Medeo Sans и Medeo Mono, значки Lucide). `docs/design/mockup/` и `screenshots/` описывают веб-панель, которой больше нет. Не менять стиль без согласования.
- Логотип используем текущий (пиксельный, `web/public/icon.svg` и PNG из `web/public/`: в `web/` остались только эти файлы, на них ссылаются README и сайт), нового не рисуем. В макете `redesign` стоит временный значок.
- Веб-панель удалена в 0.10.0-beta.17: интерфейс сервера это приложение `app/` (порт приложения, TLS, закреплённый сертификат). Вся работа в приложении `app/` и на сервере. Релизы пока только бетами (`vX.Y.Z-beta.N`) и только по команде владельца.
- Шрифты Medeo (OFL: Medeo Sans, Medeo Mono; Medeo Pixel был только в удалённой веб-панели) хранить локально вместе с текстом лицензии, не подключать с CDN.
- Откат сети и файрвола выполняет агент (таймер 30 с), не сервер.
- Секреты только с правами 600. Опасные действия требуют подтверждения. Все действия администратора пишутся в журнал аудита.
- Работай этапами из PROMPT.md, по одному за раз. Перед реализацией этапа покажи план и дождись подтверждения.
- К каждому изменению: тесты и обновление документации.
